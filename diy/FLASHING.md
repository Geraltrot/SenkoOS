# Прошивка и обновление SenkoPhone 1.0

Инструкция для платы SenkoPhone 1.0 из `diy/README.md`: ESP32 DevKit V1 (WROOM-32, 4 МБ) + EBYTE E22-900M30S + OLED SH1107.
Файлы берутся из раздела «Выпуски» репозитория. Передавать другим можно файлы начиная с **v1.1.2**: в более ранних в демо-данных страницы остались личные данные.

## Какой файл нужен

| Файл | Что внутри | Куда пишется | Когда |
|---|---|---|---|
| `<тег>-merged.bin` | загрузчик + таблица разделов + otadata + приложение | USB, адрес `0x0` | первая прошивка чистой платы, восстановление |
| `<тег>.bin` | только приложение | OTA через панель или USB, адрес `0x10000` | обновление уже прошитой платы |

Тег устроен так: `v<версия>-e22wroom-mc<версия MeshCore>-<ГГГГММДД>`, например `v1.1.2-e22wroom-mc1.18.0-20261113`.

> ⚠️ `-merged.bin` **никогда не загружайте через OTA** («Обслуживание» в панели) — это образ для адреса `0x0`, а OTA пишет в раздел приложения.

## 1. Первая прошивка чистой платы

### Что понадобится
- USB-кабель **с данными** (не только зарядный).
- Драйвер USB-UART платы: CH340 или CP2102 — смотрите на чип рядом с USB-разъёмом. В Windows после подключения в «Диспетчере устройств» → «Порты (COM и LPT)» должен появиться новый COM-порт.
- Файл `<тег>-merged.bin` из выпуска.
- Один из инструментов: браузер Chrome/Edge (вариант А) или Python с `esptool` (вариант Б).

### Режим загрузки
Обычно esptool переводит плату в режим загрузки сам. Если подключиться не удаётся (`Failed to connect`, `Wrong boot mode`), сделайте вручную: **зажать BOOT → нажать и отпустить RESET (EN) → отпустить BOOT**, затем повторить попытку. На платах с CH340 автосброс часто не работает — тогда только так.

### Вариант А. Из браузера (без установки программ)
1. Откройте в Chrome или Edge веб-версию esptool от Espressif: `https://espressif.github.io/esptool-js/`.
2. Baudrate `460800` (если будут ошибки — `115200`) → «Connect» → выберите COM-порт платы.
   Проверка: в журнале строка вида `Chip is ESP32-D0WD…`, `Flash size 4MB`.
3. Для чистой или чужой платы нажмите «Erase Flash» и дождитесь окончания (до минуты).
4. В таблице файлов: адрес **`0x0`**, файл `<тег>-merged.bin` → «Program».
   ⚠️ Проверьте адрес: в поле может стоять `0x1000` по умолчанию. С `0x1000` плата не запустится (`invalid header: 0xffffffff` в цикле).
   Проверка: в конце `Hash of data verified`.
5. «Disconnect», нажмите RESET на плате. На экране появится логотип MeshCore, затем имя и параметры радио.

### Вариант Б. Командой esptool
```powershell
pip install esptool
python -m esptool --chip esp32 --port COM3 --baud 460800 erase_flash
python -m esptool --chip esp32 --port COM3 --baud 460800 write_flash 0x0 v1.1.2-e22wroom-mc1.18.0-20261113-merged.bin
```
`COM3` замените на свой порт. В esptool 5 команды пишутся через дефис (`erase-flash`, `write-flash`); старые имена с подчёркиванием тоже принимаются.
Проверка: `Hash of data verified.` и `Hard resetting via RTS pin...`.

> `erase_flash` стирает всё, включая ключ узла. Для чистой платы это и нужно; для платы, которую нужно сохранить, его не делайте (см. раздел 3).

## 2. Первая настройка через мастер (с v1.2.0)

Пока на плате не задан Wi-Fi, она сама поднимает точку доступа для настройки. На экране:
`SETUP` → имя сети `SenkoPhone-Setup-XXXX`, пароль (8 цифр) и адрес `http://192.168.4.1/`.

1. Подключите телефон или ноутбук к этой сети паролем с экрана. Страница настройки откроется сама; если нет — откройте `http://192.168.4.1/`.
2. Заполните: **новый пароль администратора** (6–15 символов, обязательно), имя, координаты (можно позже), домашний Wi-Fi из списка найденных сетей и его пароль. Радио трогайте, только если ваша сеть на другом профиле.
3. «Сохранить». Точка настройки выключится, плата подключится к домашней сети, её адрес появится на экране. Откройте `http://<адрес>/` из домашней сети и войдите новым паролем.

Открыть мастер снова: **три быстрых нажатия кнопки** на плате, команда `wifi setup` по USB или «Обслуживание» → «Мастер настройки» в панели. Точка настройки выключается сама через 15 минут без подключений.

## 2а. Первая настройка по USB (запасной путь)

Подключите терминал к COM-порту на **115200** бод: PuTTY (Serial), монитор порта Arduino IDE или `pio device monitor -b 115200`. Если в терминале пусто — отключите DTR/RTS (иначе ESP32 остаётся в сбросе) и нажмите Enter.

1. **Сразу смените пароль администратора** — по умолчанию он `password`, и с ним в веб-панель пустят любого в вашей сети:
   ```
   password <новый пароль>
   ```
2. Имя, координаты и, если нужно, радиопрофиль вашей сети:
   ```
   set name <имя ретранслятора>
   set lat <широта>
   set lon <долгота>
   get radio
   set radio <частота>,<bw>,<sf>,<cr>      (только если ваша сеть работает не на 868.918,62.5,9,7)
   ```
   После `set radio` нужна перезагрузка: `reboot`.
3. Wi-Fi для веб-панели (пароль хранится только в плате):
   ```
   wifi ssid <имя сети>
   wifi pwd <пароль>
   wifi
   ```
   Проверка: `wifi` показывает IP; он же появляется на экране.
4. Проверка версии и объявление в сеть:
   ```
   set advert.interval 60
   diy
   advert
   ```
   `advert.interval` — как часто узел объявляет себя соседям (минуты, 60–240). На новой плате это 2 минуты — лишняя нагрузка на эфир.
   `diy` выводит название платы, версию, тип сборки (`[release]`, `[beta]` или `[dev]`) и версию MeshCore.
5. Откройте в браузере `http://<IP платы>/` и войдите паролем администратора. При желании задайте отдельный пароль веб-входа: «Обслуживание» → пароль веб-входа.

Полный список команд — `docs/cli_commands.md`, наши дополнения (`diy`, `wifi …`) — в `diy/README.md`.

> Веб-панель работает по HTTP: используйте её в домашней сети или через VPN, не пробрасывайте порт 80 в интернет.

## 3. Обновление прошитой платы

Обновление `<тег>.bin` меняет только приложение: ключ узла, имя, радио, пароли, Wi-Fi и блокировки сохраняются.

### Способ 1. По Wi-Fi через панель (основной)
1. Скачайте `<тег>.bin` из выпуска (без `-merged`).
2. Панель → «Обслуживание» → выберите файл → загрузить.
3. Дождитесь сообщения «Готово» — плата перезагрузится сама. **Не сбрасывайте и не отключайте питание до «Готово»**, иначе останется старая прошивка.
4. Проверка: в шапке панели новая версия и метка `релиз` / `бета` / `dev`; команда `diy` в «Консоли».

Во время загрузки ретрансляция продолжает работать (загрузку принимает отдельная задача на порту 8081 по одноразовому токену).

### Способ 2. По USB
```powershell
python -m esptool --chip esp32 --port COM3 --baud 460800 write_flash 0x10000 v1.1.2-e22wroom-mc1.18.0-20261113.bin
```
⚠️ Если плату раньше обновляли по OTA, она может загружаться из второго слота (`app1`), а USB пишет в первый (`app0`) — после прошивки останется старая версия. Тогда дополнительно сотрите метку слота (ключи и настройки не затрагиваются):
```powershell
python -m esptool --chip esp32 --port COM3 erase_region 0xE000 0x2000
```
Проверка: `diy` показывает новую версию.

### Откат
Прошейте `<тег>.bin` предыдущего выпуска тем же способом (OTA или USB).

### Если плата не загружается
Прошейте `<тег>-merged.bin` на `0x0` **без** `erase_flash`. Ключ узла и настройки MeshCore (имя, радио, пароль администратора) хранятся в разделе SPIFFS в конце флеша и сохранятся. Настройки этой прошивки в NVS — Wi-Fi, пароль веб-входа, блокировки — скорее всего придётся задать заново: образ `-merged.bin` перекрывает область NVS.
Если и это не помогло — полная прошивка с `erase_flash` по разделу 1 (узел получит новый ключ).

## Частые проблемы

| Симптом | Что делать |
|---|---|
| В терминале по кругу `invalid header: 0xffffffff` и `RTCWDT_RTC_RESET` | нет загрузчика: `-merged.bin` записан не на `0x0` или после «Erase» залит обычный `.bin`. Перепрошить по разделу 1: `erase_flash`, затем `-merged.bin` на `0x0` |
| `Failed to connect to ESP32` | ручной режим загрузки (BOOT → RESET → отпустить BOOT); другой кабель; закрыть терминал, занимающий COM-порт |
| Нет COM-порта | драйвер CH340/CP2102; кабель с данными |
| В терминале пусто | 115200 бод, отключить DTR/RTS, Enter |
| `nvs_open failed: NOT_FOUND` при первом запуске | до v1.1.3 — безвредно: настроек ещё нет; пропадёт после первой сохранённой настройки |
| После USB-обновления версия старая | `erase_region 0xE000 0x2000` (раздел 3) |
| Не пускает в панель | войти паролем администратора; сменить его по USB: `password <новый>` |
| Нет Wi-Fi | `wifi` — статус; заново `wifi ssid …` / `wifi pwd …`; сеть только 2,4 ГГц |
